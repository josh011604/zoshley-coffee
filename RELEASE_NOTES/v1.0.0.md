# v1.0.0 — Zoshley Coffee Shop

Release date: 2026-05-24

Highlights
- Checkout improvements: Map autocomplete accepts typed addresses (press Enter) and the checkout flow retries if delivery coordinates are not available in the database.
- Database migration: added `delivery_lat` and `delivery_lng` columns to `orders` to support delivery routing and ETA/fee calculations.
- Map UX: improved `MapAutocomplete` and `MapPreview` for better delivery selection and preview.
- Robustness: frontend now tolerates missing delivery columns and retries inserts without coords when necessary.
- CI / Deploy: GitHub Actions workflow and `netlify.toml`/Vercel-compatible deployment settings added to enable automated builds and deploys.
- Minor: Removed several lint warnings and improved code quality; added a "What's New" banner to the homepage.

Upgrade notes
- If you run Supabase migrations locally, apply the new migration under `supabase/migrations/` to add delivery coordinate columns.
- If you rely on release automation, add your `NETLIFY_AUTH_TOKEN`/`NETLIFY_SITE_ID` or Vercel Deploy Hook in the project settings.

Deploy
- The site is connected to the `main` branch; pushing this commit should trigger your Vercel/GitHub CI to run a build and deploy.
